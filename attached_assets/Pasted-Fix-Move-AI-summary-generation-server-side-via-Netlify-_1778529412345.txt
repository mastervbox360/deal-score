Fix: Move AI summary generation server-side via Netlify Function
The current implementation calls the Anthropic API directly from the browser using a VITE_ prefixed key. This exposes the API key in the browser. We need to move this server-side.
Step 1 — Create a new Netlify Function: netlify/functions/generate-summary.ts
It should accept a POST request with a JSON body containing: address, strategy, purchasePrice, grossYield, netYield, cashFlow, roi, dealScore, whyThisStrategy. It calls the Anthropic API using claude-sonnet-4-20250514 with these values in the prompt and returns a 3–4 sentence executive summary as JSON: { summary: string }. The Anthropic API key should be read from process.env.ANTHROPIC_API_KEY (no VITE_ prefix — this is server-side only).
Use this fetch pattern to call Anthropic (do not use the SDK — keep it as a plain fetch to avoid dependency issues in Netlify Functions):
fetch('https://api.anthropic.com/v1/messages', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': process.env.ANTHROPIC_API_KEY,
    'anthropic-version': '2023-06-01'
  },
  body: JSON.stringify({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 300,
    messages: [{ role: 'user', content: yourPromptHere }]
  })
})
