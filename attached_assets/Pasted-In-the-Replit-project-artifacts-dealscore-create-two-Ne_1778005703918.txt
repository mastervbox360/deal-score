In the Replit project artifacts/dealscore, create two Netlify serverless functions and update the app to use them instead of calling the government APIs directly.

Step 1 — Create the netlify functions directory

Create the file artifacts/dealscore/netlify/functions/land-registry.js:

exports.handler = async (event) => {
  const postcode = event.queryStringParameters?.postcode;
  if (!postcode) {
    return { statusCode: 400, body: JSON.stringify({ error: 'postcode required' }) };
  }

  try {
    const url = `https://landregistry.data.gov.uk/data/ppi/transaction-record.json?propertyAddress.postcode=${postcode}&_pageSize=1&_sort=-transactionDate`;
    const response = await fetch(url);
    const data = await response.json();
    return {
      statusCode: 200,
      headers: { 'Content-Type': 'application/json', 'Access-Control-Allow-Origin': '*' },
      body: JSON.stringify(data),
    };
  } catch (err) {
    return { statusCode: 500, body: JSON.stringify({ error: err.message }) };
  }
};


Create the file artifacts/dealscore/netlify/functions/epc-lookup.js:

exports.handler = async (event) => {
  const postcode = event.queryStringParameters?.postcode;
  if (!postcode) {
    return { statusCode: 400, body: JSON.stringify({ error: 'postcode required' }) };
  }

  try {
    const url = `https://epc.opendatacommunities.org/api/v1/domestic/search?postcode=${postcode}&size=1`;
    const response = await fetch(url, {
      headers: { 'Accept': 'application/json' },
    });
    const data = await response.json();
    return {
      statusCode: 200,
      headers: { 'Content-Type': 'application/json', 'Access-Control-Allow-Origin': '*' },
      body: JSON.stringify(data),
    };
  } catch (err) {
    return { statusCode: 500, body: JSON.stringify({ error: err.message }) };
  }
};


Step 2 — Create netlify.toml at artifacts/dealscore/netlify.toml:

[build]
  publish = "dist/public"
  functions = "netlify/functions"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200


Step 3 — Update lookupPropertyData in artifacts/dealscore/src/pages/Home.tsx

Find the two fetch calls inside lookupPropertyData and replace them:

Replace:

const landRegPromise = fetch(

const epcPromise = fetch(

With:

const epcPromise = fetch(
