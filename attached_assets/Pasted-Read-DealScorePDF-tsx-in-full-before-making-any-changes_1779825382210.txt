TASK 2 — ADD KEY METRIC TO ALL THREE COVER STYLES

The cover page currently shows: strategy label, address, 
date, prepared by. It needs one additional prominent 
signal — the strategy-specific key metric — displayed 
prominently on the cover, matching the live bar logic.

Add a key metric computation function near 
computeCalloutMetrics:

function computeCoverKeyMetric(props: DealScorePDFProps): 
  { label: string; value: string } {
  const dt = props.dealType;
  if (dt === 'BTL' || dt === 'HMO' || dt === 'SA' || 
      dt === 'SOCIAL') {
    const cf = dt === 'BTL' ? props.btlResults.monthlyCashFlow
      : dt === 'HMO' ? props.hmoResults.monthlyCashFlow
      : dt === 'SA' ? props.saResults.monthlyCashFlow
      : props.socialResults.monthlyCashFlow;
    return { label: 'Cash Flow', value: fc(cf) + '/mo' };
  }
  if (dt === 'FLIP') {
    return { 
      label: 'Profit on Cost', 
      value: fp(props.flipResults.profitOnCost) 
    };
  }
  if (dt === 'BRRR') {
    const moneyOut = props.brrrResults.moneyOut && 
      props.purchasePrice > 0;
    return { 
      label: 'Cash Left In', 
      value: moneyOut ? '∞ recycled' : 
        fc(props.brrrResults.cashLeftInDeal) 
    };
  }
  // R2R
  return { 
    label: 'Monthly Profit', 
    value: fc(props.r2rResults.monthlyProfit) + '/mo' 
  };
}

Then call this function near the top of the 
DealScorePDF component, alongside the other 
pre-computed values:
const coverKeyMetric = computeCoverKeyMetric(props);
